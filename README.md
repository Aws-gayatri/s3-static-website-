# 🚀 S3 Static Website Hosting Project

## 📌 Overview
This project demonstrates hosting a static website using Amazon S3.

## ⚙️ Steps Performed
- Created S3 bucket
- Disabled block public access
- Uploaded index.html
- Enabled static website hosting
- Added bucket policy for public access

## 🌐 Live Demo
http://gayatri-s3-site-001.s3-website-ap-south-1.amazonaws.com

## 🛠️ Tech Used
- AWS S3

## 📸 Output
Website successfully hosted and accessible publicly.
